# Synapse — Frontend

Interface React (Vite) de **Synapse** : landing, authentification, tableau de bord et workspace de graphes (React Flow).

Documentation complète du projet (installation, API, architecture) : [README à la racine](../README.md).

## Commandes

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Stack

React 19, Vite 7, React Router, Tailwind CSS, `@xyflow/react`, Motion, Lucide.
